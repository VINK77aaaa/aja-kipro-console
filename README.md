# AJA Ki Pro 中文控制台

给 AJA Ki Pro Ultra 12G（http://10.10.12.53/ ，设备系统名 AJA3）配的中文操作面板。
**不改动设备固件和英文页面**——英文原版照常访问，两者互不影响。

支持 **2~8 台设备**：每台 IP 不同，面板顶部可切换，所有读写都作用于当前选中的那台。

## 启动

双击 `启动中文控制台.bat`，会自动打开浏览器访问 **http://127.0.0.1:8321**。

命令行方式：在本目录下打开命令行，执行

```bat
node server.js
```

需要 Node.js（本机已装 v24）。关闭窗口或 Ctrl+C 即停止服务；停止后面板显示"离线"，设备本身不受任何影响。

## 功能

- **设备切换**（多机时显示）：顶部标签列出所有设备及其在线状态，点击切换
- **添加 / 移除设备**（顶部按钮）：
  - 「＋ 添加设备」：填名称（可留空，自动命名）+ IPv4 → 面板**只读探测一次** `eParamID_ProductID` 确认是在线的 Ki Pro → 通过才追加写入 `devices.txt` 并**热重载**（不用重启面板），随后自动切到新设备
  - 探测失败会明确区分原因：IP 格式不对 / 连接超时（不可达）/ 有响应但不是 Ki Pro / IP 或名称重复
  - 设备标签上的「×」＝移除该设备（删 `devices.txt` 对应行，有确认框）。**最后一台不允许从面板移除**，避免列表变空后静默回退到默认设备
  - 添加/移除**不会向设备写入任何参数**；只有只读 GET
- **一键录制 / 一键停止**（顶部「⏺ 全部录制」「⏹ 全部停止」）：软 Gang 总控
  - 弹出确认框列出**将下发的在线设备清单**（名称 + IP），可勾选参与本次群发的子集
  - 确认后对每台群发 `eParamID_TransportCommand=3`（录）/ `=4`（停），走带是瞬时命令，**不回读校验**（与单机按钮一致）
  - **逐台回报结果**：成功几台、失败几台、哪台失败及原因；部分失败不算整体失败
  - 单机的「录制 / 停止」按钮保持不变，两者互不影响
- **状态区**（每 3 秒自动刷新）：时码、走带状态、视频输入、录制格式、当前片段、介质槽、剩余空间
- **走带控制**：上一片段 / 播放 / 停止 / 录制 / 下一片段（录制有确认弹窗）
- **拍摄前命名**：拍摄前把片段名、Take 条号、后缀一次性设好
  - 启用自定义命名（UseCustomClipName）、自定义片段名（CustomClipName，自由文本）
  - Take 条号（CustomTake）、片段名后缀方式（ClipAppend：无 / 字母）、后缀字母（AlphaAppend：A–Z）
  - 当前片段号（ClipNumber，只读显示）
  - 改动先在本地暂存，点「下发命名设置」才一次性写入（弹确认框，逐项显示旧值 → 新值）
- **设备配置**（下拉修改，弹确认框后下发）：
  - 录制与编码：介质状态、编码通道、录制通道数、文件封装、通道 1–4 编码
  - 音频：音频通道数、通道 1–4 音频输入、耳机监听通道
  - 播放与输出：播放介质、SDI 监视通道、HDMI 输出通道
- **介质素材**：读取设备剪辑列表与播放列表（插卡录制后可见）
- **告警**（每 3 秒自动刷新，**只读**）：把设备 Alarms 系统的告警中文化展示
  - 全部正常时显示绿色「全部正常 —— 已检查 48 项告警，无异常」
  - 有告警时按严重级别排序（严重 / 错误 / 警告），逐条显示**中文名称 + 中文说明 + 设备原文**
  - **声光提醒**：出现达到触发级别的告警时，发出约 3 秒的警告音，同时页面全屏闪烁 + 告警卡片持续脉冲
    - 触发级别可切换：仅「严重」/「严重」+「错误」（默认）/ 全部级别
    - **只在告警「新出现」时响**，同一条告警持续存在不会反复响；消失后再出现会重新响
    - 「静音」按钮可关闭声音（页面动画保留）
    - 设置存在浏览器本地（`localStorage`），下次打开仍是上次的选择
  - 只读：不提供「清除告警」，不向设备写任何参数
- **健康状态**：面板服务运行时长、各设备在线情况

所有下拉选项实时取自设备本身（英文页同款数据源），中文括号内为设备原始英文值，方便与英文页对照。

## 分辨率 / 帧率：为什么没有修改选项

**因为录像机侧没有可写的录制格式参数。**

Ki Pro 的录制格式**跟随 SDI 输入信号**，分辨率/帧率在**信号源（摄像机）端**决定。已用设备自带的参数表
`http://<设备IP>/desc.json`（本机 v2.8.0.24 共 285 个参数）逐个核对：

| 参数 | 界面名 | 参数表标记 | 能否写 |
|---|---|---|---|
| `eParamID_DetectInputFormat` | Input Format | `readonly` | ❌ 侦测 |
| `eParamID_DetectMediaFormat` | Media Format | `readonly` | ❌ 侦测 |
| `eParamID_RecordFormat` | Record Format | `readonly` | ❌ 侦测 |
| `eParamID_DetectInputTSIFormat` | Image Division | `readonly` | ❌ 侦测 |
| `eParamID_MediaSpeed` | Media Speed | `readonly` | ❌ 侦测 |

设备前端 JS（`/js/kipro.common.js`）也把这一组参数当**只读文本**渲染（`ElementText`），与参数表一致。

参数表里**唯一可写、名字带 "Frmt" 的是 `eParamID_VideoSGFormat`（Video SG Frmt）**——那是
**设备内置信号发生器（测试图）的格式**，不是录制格式；它只影响设备自己产生的测试信号。

参数表里**没有任何**名字含 `resolution` / `framerate` / `fps` 的参数。

下面这些是**可写的、看着像"格式"但都不是录制分辨率/帧率**的参数，别混进来：

| 参数 | 界面名 | 实际作用 |
|---|---|---|
| `eParamID_VideoOutConvert` | Out Convert | 监视**输出**转换（None / 4K Crop to UHD / 2K Crop to 1080） |
| `eParamID_VideoInConvert` | In Convert | 输入转换 |
| `eParamID_SDIIn_VideoInputRate` | Input Data Rate | SDI **链路速率**选择（3G/6G/12G/HDMI），且对面板与网页都隐藏 |
| `eParamID_FileFormat_*` | File Format | 文件**封装**（MOV / MFX） |
| `eParamID_EncodeType_*` | Encode Type | 编码**档次**（ProRes 422/HQ/LT、DNxHD/HR…） |
| `eParamID_VideoSGFormat_*` / `eParamID_VideoSG` | Video SG Frmt / Video SG | 内置**测试信号发生器** |

要改分辨率/帧率，请调**摄像机输出**或换 SDI 信号源。面板上的这两张卡是**只读侦测显示**。

## 告警（Alarms）：面板怎么读到的

设备的告警**不是普通参数**——它们是 **protobuf 二进制**，通用读取器读不懂（这也是最初面板看不到它们的原因）。

参数表 `http://<设备IP>/desc.json` 里，`param_type` 为 `data` 且 `class_names` 含 `alarm` 的共 **48 个**。
schema 设备自带，可直接取：

```
GET http://<设备IP>/alarm.proto
GET http://<设备IP>/error.proto
```
```proto
message Alarm {
  enum State    { NORMAL = 0; ALARM = 1; }
  enum Severity { WARNING = 0; ERROR = 1; FATAL = 2; }
  required State    state    = 1;
  optional Severity severity = 2;
  repeated Error    error    = 3;   // { string text; string short_text; }
}
```

读取 `/config?action=get&paramid=eParamID_XXX_Alarm`，`value` 是 base64 protobuf；
`server.js` 里做了个零依赖的最小 protobuf 解码器，解出 `state` / `severity` / `error[].text`。

**严重级别是每条告警的静态属性**（`NORMAL` 时也带着），本机实测分布：

| 级别 | 条数 | 例子 |
|---|---|---|
| 严重 FATAL | 1 | 风扇停转 |
| 错误 ERROR | 20 | 介质已满、同步信号不匹配、未安装介质、录制格式问题 |
| 警告 WARNING | 27 | 无视频输入、介质空间不足、丢帧、温度偏高 |

面板**只读展示**：不做「清除告警」（设备网页有 Clear Alarms，会下发 `eParamID_Clear_Alarms=1`，
属于写操作，面板的安全边界里不做）。设备在告警抬升时可能追加更详细的文案
（例如「无视频输入」抬升时设备会给 `No SDI input detected`），这些**原文会一并展示**，不丢信息。

### 声光提醒怎么响

- 声音是**浏览器现场合成的**（Web Audio API 方波，高低交替的双哔为一组，组间停顿），
  **不依赖任何音频文件**，所以面板依然是零依赖、零外部资源。
- **只在告警「新出现」时触发**：面板记住上一次「正在报」的告警 id 集合，只对新增的响。
  同一条告警持续存在不会每 3 秒反复响；它消失后再次出现会重新响。
- **页面打开时的第一条基线不响**（否则每次打开面板都会被存量告警吓一跳），
  但告警卡片会立刻进入脉冲状态，视觉上仍然醒目。
- 浏览器有**自动播放限制**：页面必须先被点过一次才能出声。面板会在首次点击/按键时预热音频；
  若仍被拦截，会弹出提示引导点击页面。
- 触发级别默认是「严重 + 错误」。**唯一那条「严重」告警是风扇停转**；「错误」有 20 条
  （介质已满、未安装介质、录制格式问题、同步信号不匹配……）。若嫌吵可切到「仅严重」。

## 写入与校验

每次改动设置都会**下发后自动回读**：面板会重新读一次该参数，确认设备真的接受了新值。

- 回读一致 → 提示"已下发并回读确认"
- 回读不一致（设备拒绝了该值，例如录制中不允许改编码）→ 明确提示"未生效，设备现值仍是 X"

走带命令（播放/停止/录制等）是瞬时命令，不做回读校验，只确认下发成功。

## 多机配置

**方式一（推荐）**：面板顶部「＋ 添加设备」，填名称 + IP，探测通过后自动写入并生效（无需重启）。
设备标签上的「×」可移除。

**方式二**：编辑同目录的 `devices.txt`，一行一台：

```
AJA1@10.10.12.51
AJA2@10.10.12.52
AJA3@10.10.12.53
```

只写 IP 也可以（会自动命名为 AJA1、AJA2……）。以 `#` 开头的行为注释。

读取优先级：环境变量 `AJA_DEVICES` > `devices.txt` > 环境变量 `AJA_DEVICE_IP` > 默认单台 `10.10.12.53`。

手动改完 `devices.txt` 后需要**重启面板**生效；用面板上的「＋ 添加设备 / ×」则自动生效。
注意：若设了环境变量 `AJA_DEVICES`，面板的添加/移除会被拒绝（写文件不生效），需改用文件或清掉该变量。

## 与英文版的关系

中文面板只是一个"旁路"：本机 `server.js` 把页面请求转发到设备的 HTTP API
（`/config?action=get|set`、`/options`、`/clips`），设备固件、英文页面、SDI 录制流程完全不感知。
浏览器直连设备会被跨域拦住，所以必须通过本机服务转发。

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `AJA_DEVICES` | 空 | 设备列表，逗号分隔，如 `A机@10.10.12.51,B机@10.10.12.52`（优先级最高） |
| `AJA_DEVICE_IP` | `10.10.12.53` | 单台设备 IP（旧配置，仍兼容） |
| `AJA_DEVICE_PORT` | `80` | 设备 HTTP 端口 |
| `AJA_PANEL_PORT` | `8321` | 面板端口 |

## 安全边界

- **有**：查看全部状态、改上表所列配置与拍摄前命名、走带命令（单机与群发，均有确认框）、
  按 IP 添加/移除设备（添加只做**只读探测**，不写任何设备参数）、查看设备告警（**只读**）
- **没有**（避免误操作，故意不做）：格式化介质、删除片段、固件升级、网络/密码设置、重启设备、**清除设备告警**
- 群发总控**只发走带命令**（录制/停止），不动任何配置类参数

## 文件

- `server.js` —— 本机代理服务（Node 零依赖），多机设备列表 + 写后回读校验
- `public/index.html` —— 中文单页界面
- `devices.txt` —— 多机设备列表（一行一台）
- `param-enums.json` —— 从设备前端 JS 提取的枚举表（开发参考，可删）
- `启动中文控制台.bat` —— 双击启动本面板（推荐入口）
