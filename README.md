# 达芬奇助手（图片实时导入 + AJA Ki Pro 中文控制台）

一套给现场调色/录制工作流用的小工具，两块功能可以单独用，也可以一起用：

| 模块 | 作用 | 入口 |
|---|---|---|
| **图片实时导入** | 监视文件夹，新图片自动归档并导入达芬奇时间线 | `启动达芬奇助手.bat` 或 `实时导入.bat` |
| **AJA 中文控制台** | AJA Ki Pro Ultra 12G 的中文操作面板（2~8 台设备） | `启动达芬奇助手.bat` 或 `aja-中文控制台/启动中文控制台.bat` |

**推荐直接双击 `启动达芬奇助手.bat`** —— 一次把两个服务都拉起来（达芬奇没开也会顺手启动），并自动打开控制台页面。

---

## 一、图片实时自动导入

监视指定文件夹，一有新图片就自动备份到桌面存档文件夹，并从存档位置导入 DaVinci Resolve 媒体池、追加到时间线末尾。
为"边调色边收集截图/参考图"的工作流设计，不用再手动拖拽导入。

### 功能

- 实时监视文件夹：新图片复制完成后几秒内自动归档，并按文件名自然顺序上时间线（每张时长可配，默认 5 秒）
- 时间线滚动清理：自动导入的图片最多保留最近 16 张（可配），超过自动删最旧的，文件仍留在归档文件夹
- 监视文件夹始终保持干净，图片统一定期备份位置在桌面"调试静帧存档"
- 达芬奇从归档位置导入，清理监视文件夹**永远不会造成"媒体离线"**（红色片段）
- 导入后自动切回你原来所在的页面（比如调色页），不会被拽到剪辑页
- 启动时文件夹里已有的图片会自动补导入；已被时间线引用的图片会跳过，
  等时间线上删掉对应片段后自动归档清理
- 达芬奇没开或没进入项目时自动等待，图片排队，进入项目后自动补导
- **单实例保护**：重复启动会自动退出（占用本机回环端口 8322 当锁，不会留下僵尸锁）
- **心跳状态**：每轮写 `.watcher-status.json`，可在 AJA 中文控制台的「健康状态」区看到
  监视器是否在跑、达芬奇是否连上、队列里还有多少张待导入

### 使用方法

1. 把 `watch_images.py` 和 `实时导入.bat` 放到任意文件夹（两个文件放在一起）
2. 双击 `实时导入.bat`（或根目录的 `启动达芬奇助手.bat`）—— 会最小化一个黑色监视窗口，达芬奇没开会自动帮你启动
3. 把图片丢进同目录下的 `图片` 文件夹，几秒后自动出现在当前时间线末尾
4. 关闭黑色窗口即停止监视

### 环境要求

- DaVinci Resolve 21（实测通过）；17/18 的旧版接口兼容代码已内置
- Python 3.6+（Windows `py` 启动器），免费版达芬奇即可，无需 Studio
- Windows 系统（脚本用了 Windows 弹窗和 bat 启动）

### 配置

改 `watch_images.py` 开头的配置区：

| 配置 | 说明 | 默认值 |
|---|---|---|
| `IMAGE_FOLDER` | 监视的文件夹 | 脚本同目录的 `图片` 文件夹 |
| `STILL_SECONDS` | 每张图片在时间线上的时长（秒） | 5 |
| `POLL_INTERVAL` | 扫描文件夹的间隔（秒） | 2 |
| `MAX_TIMELINE_ITEMS` | 时间线上最多保留的自动导入图片数量，超过删最旧的（0 = 不限制） | 16 |
| `ARCHIVE_FOLDER` | 归档备份的位置 | 桌面\调试静帧存档 |
| `SINGLE_INSTANCE_PORT` | 单实例锁占用的本机端口 | 8322 |

### 注意事项

- 时间线片段引用桌面存档里的源文件，归档文件夹里的图片请不要移动/删除，否则会变成离线媒体
- 旧版脚本导入过的图片会留在监视文件夹里不动（移动会离线），时间线上删掉对应片段后会自动归档
- 归档失败分两种情况处理：**文件被占用**（仍在监视文件夹，自动重试并暂缓归档）；
  **文件已不存在**（直接放弃并记日志，不会拿不存在的路径去白跑导入重试）
- 已经变红的"媒体离线"片段：达芬奇 21 的接口无法把片段重新指向新路径
  （RelinkClips / ReplaceClip / SetClipProperty 均不支持），只能删掉红色片段后把图片重新丢进监视文件夹重导
- 运行日志写在同目录 `监视日志.txt`，出问题先看它
- 原理：通过达芬奇官方脚本接口（`fusionscript.dll`）连接正在运行的达芬奇，不依赖第三方服务

## 二、AJA Ki Pro 中文控制台

给 AJA Ki Pro Ultra 12G 配的中文操作面板，通过本机 Node 代理转发设备私有 HTTP API，
**不改动设备固件和英文页面**。支持 2~8 台设备切换，写操作带回读校验。

详见 [`aja-中文控制台/README.md`](aja-中文控制台/README.md)。

要点：

- 启动后访问 http://127.0.0.1:8321
- 多台设备在 `aja-中文控制台/devices.txt` 里配置（一行一台，`名称@IP`）
- 拍摄前命名（片段名 / Take / 后缀）、走带控制、编码与音频配置、介质素材、健康状态
- 安全边界：不做格式化介质、删片段、固件升级、网络/密码设置、重启设备

## 文件一览

```
达芬奇/
├── 启动达芬奇助手.bat        ← 推荐入口：一次启动全部
├── 实时导入.bat              ← 只启动图片监视器
├── watch_images.py           ← 图片实时导入脚本
├── README.md                 ← 本文件
├── 图片/                     ← 往这里丢图片
├── 监视日志.txt              ← 运行日志
├── .watcher-status.json      ← 心跳状态（自动生成）
└── aja-中文控制台/
    ├── 启动中文控制台.bat    ← 只启动面板
    ├── server.js             ← Node 代理（多机 + 回读校验）
    ├── public/index.html     ← 中文界面
    ├── devices.txt           ← 多机设备列表
    └── README.md
```
